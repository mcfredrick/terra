## Open Source Projects
- **[mlco2/codecarbon](https://github.com/mlco2/codecarbon)** — Provides real-time tracking of greenhouse gas emissions from computational workloads, integrating with Python runtimes and cloud platforms to quantify the carbon impact of software and AI development. Essential for engineers assessing and reducing the environmental footprint of code and models.
- **[green-coding-solutions/green-metrics-tool](https://github.com/green-coding-solutions/green-metrics-tool)** — Provides comprehensive metrics for software energy consumption and carbon emissions with timeline tracking, Git integration, and interactive dashboards to support sustainable software engineering practices. Engineers can use the comparative analysis and power-consumption monitoring to optimize code and infrastructure for lower emissions.
- **[Zara-Toorox/Solar-Forecast-ML](https://github.com/Zara-Toorox/Solar-Forecast-ML)** — Implements a local Attention Transformer model for solar photovoltaic forecasting within Home Assistant, enabling on-device generation predictions without external AI dependency. This approach is relevant for engineers exploring edge ML and privacy-preserving renewable energy integration.

## Today's Synthesis

Software engineers pivoting into climate work can extend their existing skill set by building a carbon-aware compute workflow that measures, optimizes, and time-stamps tasks to align with renewable generation. [codecarbon](https://github.com/mlco2/codecarbon) provides real-time tracking of greenhouse gas emissions from computational workloads, integrating with Python runtimes and cloud platforms to quantify the carbon impact of code and AI development. Paired with [green-metrics-tool](https://github.com/green-coding-solutions/green-metrics-tool), which delivers comprehensive energy-consumption metrics, timeline tracking, and Git-integrated dashboards, engineers can perform comparative analysis and power-consumption monitoring to strip-mine code and infrastructure for efficiency gains. A concrete next step involves coupling these tools with [Solar-Forecast-ML](https://github.com/Zara-Toorox/Solar-Forecast-ML), an on-device Attention Transformer for solar photovoltaic forecasting within Home Assistant, to predict near-term generation windows. By scheduling compute-intensive model training or data processing jobs during predicted high-solar periods, engineers directly reduce grid-drawn carbon intensity while leveraging edge-ML techniques that avoid external API dependencies. This approach is immediately actionable: install codecarbon, profile a workload, use green-metrics-tool to identify optimization targets, then configure a scheduler that queries the solar forecast model and defers execution until the carbon intensity curve dips. The result is a measurable emissions reduction loop that sits entirely within the engineer's existing toolchain, demonstrating how software optimization skills translate into tangible climate impact.
