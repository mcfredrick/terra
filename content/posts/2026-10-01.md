## Research Worth Reading
- **[Low-Rank and Lifted Semidefinite Programming for Mixed-Integer Polynomial Power Grid Optimization](https://arxiv.org/abs/2609.38435)** — Proposes a hybrid low-rank SDP and moment-based lifting framework within the Lasserre hierarchy to obtain guaranteed globally optimal solutions for nonconvex mixed-integer polynomial power grid optimization. Engineers can apply this hierarchical relaxation approach to discrete grid control problems requiring provable optimality.
- **[Less is more: error-distance scaling relation for data-efficient kilometer-scale downscaling of extreme heat](https://arxiv.org/abs/2609.40140)** — Introduces CASPER, a U-Net with structure-preserving loss that downsamples 32 km reanalysis data to 1 km resolution for temperature, humidity, and wind. Engineers can use the error-distance scaling relation to determine minimum training data needs for kilometer-scale climate downscaling.
- **[Learning to Fix: Optimisation-Aware Machine Learning for Accelerated Unit Commitment](https://arxiv.org/abs/2609.39396)** — Addresses unit commitment by using ML to predict binary commitment decisions, shrinking the MILP solver search space. The optimization-aware integration reduces computation time for power system scheduling.
- **[A library for differentiable signal processing and machine learning on the sphere](https://arxiv.org/abs/2609.39737)** — Enables differentiable signal processing and ML on S2, supporting gradient-based optimization for geophysics and atmospheric science tasks. Engineers working with spherical climate data can build end-to-end differentiable models.
- **[reGRAF: a global MPAS reforecast data set with convection-allowing refinements over the US and Europe](https://arxiv.org/abs/2609.40133)** — NVIDIA and The Weather Company generated a global MPAS reforecast dataset with convection-allowing refinements over the US and Europe. Useful for engineers needing high-resolution data for extreme event and precipitation modeling.

## Today's Synthesis

Engineers can connect three recent advances to build a practical pipeline for climate-aware grid optimization. [CASPER: error-distance scaling relation for data-efficient kilometer-scale downscaling of extreme heat](https://arxiv.org/abs/2609.40140) demonstrates how a U-Net with structure-preserving loss can downscale 32 km reanalysis to 1 km resolution for temperature, humidity, and wind while quantifying minimum training data needs via error-distance scaling. This downscaled climate data feeds naturally into [a library for differentiable signal processing and machine learning on the sphere](https://arxiv.org/abs/2609.39737), which supports gradient-based optimization for atmospheric science tasks on S2, enabling end-to-end model differentiation without custom autograd loops. Finally, [Learning to Fix: Optimisation-Aware Machine Learning for Accelerated Unit Commitment](https://arxiv.org/abs/2609.39396) uses ML to predict binary commitment decisions, shrinking MILP solver search spaces and reducing computation time for power system scheduling under predicted extreme conditions. Together, an engineer can sequence these tools: generate high-res climate forecasts, differentiate through spherical atmospheric models, and automatically optimize unit commitment with provable efficiency gains — a concrete, deployable workflow for software engineers pivoting into climate systems work.
