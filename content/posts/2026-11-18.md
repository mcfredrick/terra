## Research Worth Reading
- [Tie-Line Scheduling Using Real-Time Contraction Metrics: Hierarchical Reachable Sets for Multi-Area Inverter-Dominated Grids](https://arxiv.org/abs/2611.21858) — Proposes a hierarchical reachable-set and contraction-metric method for tie-line scheduling, bridging the timescale and modeling gap between slow supervisory congestion optimizers and fast inverter dynamics. Relevant if you work on grid optimization or control and want to see how stability guarantees get folded into scheduling.
- [AI Agents Executing an RMS and EMT Ride-Through Workflow on a 2,000-Bus Synthetic Texas Grid](https://arxiv.org/abs/2611.22167) — An engineer-supervised agent workflow runs RMS and EMT ride-through studies on the ACTIVSg2000 synthetic grid with open-source tools, testing a battery plus co-located data-center load against ride-through criteria. A concrete, reproducible example of agent-assisted power-system simulation and compliance checking.
- [Benchmarking a Grid Foundation Model for AC Optimal Power Flow](https://arxiv.org/abs/2611.22181) — Benchmarks GridSFM-Open 1.1.0, a learned foundation model, on AC optimal power flow for synthetic Texas and South Carolina grids, scoring feasibility and warm-start quality rather than objective gap alone. Useful if you're evaluating learned surrogates as accelerators for optimization solvers.

## Today's Synthesis

Start by treating the [GridSFM-Open benchmark](https://arxiv.org/abs/2611.22181) as a surrogate-model integration test rather than a standalone optimizer: wrap its warm-start outputs in a solver workflow, then use the [agent-assisted RMS/EMT ride-through pipeline](https://arxiv.org/abs/2611.22167) as an automated validation harness for the resulting schedules. A good first project is a replay benchmark: take historical load and DER profiles, compare solver iterations with and without learned warm starts, and log constraint violations, runtime, and simulation pass rates. For a team working on distributed resources, the [Michigan virtual power plant](https://www.canarymedia.com/articles/virtual-power-plants/new-net-zero-community-michigan-vpp) gives a deployment-shaped target: ingest DER telemetry, generate feasible dispatch candidates, and check them against network constraints and ride-through criteria. The practical build is a closed loop: foundation model proposes an AC-OPF solution, a deterministic solver repairs feasibility, and an agent executes dynamic simulations before approving the schedule. This turns learned acceleration into something operators can trust because the model is bounded by physics and verified by simulation, and gives clear regression tests for each upgrade.
